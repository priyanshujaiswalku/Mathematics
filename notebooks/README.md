# Jupyter Notebooks Directory

Interactive step-by-step experimentation and visualization notebooks:
- `01_autograd_and_poisson.ipynb`: Understanding PyTorch autograd and solving a 1D Poisson problem.
- `02_burgers_continuous_forward.ipynb`: Solving 1D Burgers' equation using continuous-time PINN.
- `03_burgers_inverse_discovery.ipynb`: Parameter discovery ($\nu$) from synthetic observations.
- `04_error_and_fdm_benchmark.ipynb`: Direct comparison with Finite Difference Method.
